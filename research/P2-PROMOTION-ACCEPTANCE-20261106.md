# Picket and Gambrel geometry — release acceptance

Version: 2026-11-06. Two P2 research intents are promoted to P1 following geometry and browser validation, giving 28 active tool routes and three held P2. All 152 original Semrush keyword rows remain unchanged.

## Fence Picket
Reference starts at the inside face of the left fence post, ending at the inside face of the right post. For n equal-width pickets, choose n+1 equal gaps including both panel boundaries, or n−1 gaps with both outer picket faces flush. Automatic mode solves the minimum count for the user-entered maximum clear gap; fixed-count mode solves the resulting physical gap. A stepped parabolic profile gives separately flat-cut top heights for each board — NOT a circular arch or a full-size cutting template. Reference fixture: 120in opening, 3.5in actual picket width, max gap 4in -> 16 boards and 17 gaps each 64/17in. Real post movement, local code, wind loads, structural supports and fastening are excluded.

## Gambrel Roof
Symmetric two-slope profile. The lower run begins at the EAVE and ends at the break, measured horizontally; the upper run continues to the central ridge. Four actual slope segments are exported as 2D endpoints, physical lengths and plane areas. Reference: 240in building span, 12in side eave overhangs, lower horizontal run 60in, lower pitch 12:12, upper pitch 4:12, giving profile coordinates (0,0), (60,60), (132,84), (204,60), (264,0). Sum of the four individual sloped roof faces conserves total area. Structural gambrel truss design, member sizes, bearing, fasteners and snow/wind approval are excluded.

CI evidence required: Node numerical fixtures, 28-route browser screen/SVG/CSV contract, print-PDF and cross-browser regression, static and offline release validation. No physical print or stock trial is claimed. Preview stays noindex,nofollow,noarchive.
