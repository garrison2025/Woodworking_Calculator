# Measured deck stock-loss budgeting — release acceptance (2026-11-06)

An identified risk existed in the high-volume Deck Board Calculator: a plank whose nominal length exactly equaled the full row was previously treated as one usable purchased piece, even if rough end trimming and a crosscut were needed. A purely nominal quantity can understate the actual supplier purchase.

This change adds two optional user inputs: **end trim at EACH stock end** and **one deliberately conservative crosscut kerf reserved for EACH purchased piece**, both zero by default for backward compatibility. The calculation uses `net usable piece length = measured stock length − 2×end trim − kerf reserve` before `pieces per row = ceil(row length/net usable length)` and applies the existing percentage reserve. One charged kerf per piece is a *purchasing allowance*, not a claim that the actual saw needs that kerf for every piece; it may overestimate loss. The rows' physical board-face layout is unchanged.

Independent example: width 95 in, row length 120 in, face 5.5 in, between-board gap 0.25 in, supplier stock 60 in, trim 0.75 in EACH end and 0.125 in kerf. The 17 rows still sum to 95 in and the last rip is 3 in. Grossly two nominal pieces would reach 120 in, but net usable stock is 58.375 in, so **three pieces per row and 57 purchased pieces including 10% reserve** are estimated. These 57 pieces are NOT certified for real joist support, end-bearing, fasteners or any actual full-length joint plan. A nominal 120 in supplier plank with 0.25 in trims on both ends plus 0.125 in kerf similarly does NOT cover a 120 in row.

Safeguards: reject negative, nonrepresentable or over-consuming stock reserves; cap unrealistic piece counts for responsiveness; show an explicit unverified-joist-joints notice whenever more than one piece is needed. `tests/deck-board-stock-reserve.test.mjs` checks independent arithmetic and in/mm equivalence; `tests/e2e/deck-board-stock-reserve.spec.mjs` checks mobile viewport, input unit conversions, UI warnings, SVG faces, CSV exports, invalid state clearing, and sample/reset behavior.

Limits: no bill of materials by actual joinery, no reuse of offcuts, no safe saw cuts, no structural bearing design, no verified supplier stock or physical test. No new SEO route, no edits to the original 152-keyword Semrush export, no change to preview noindex.
